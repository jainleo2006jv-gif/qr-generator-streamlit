# 🚀 QR Generator Streamlit

A futuristic and modern QR Code Generator built using HTML, CSS, JavaScript, and Python Streamlit.

Generate stylish animated QR codes instantly with customizable colors, sizes, animations, and downloadable formats.

# ✨ Features

* 🎨 Custom QR foreground and background colors
* 🌌 Futuristic cyberpunk UI
* 🌀 3D animated QR effects
* 📏 Adjustable QR code size
* ⚡ Error correction support
* 💾 Download as PNG or JPEG
* 📱 Responsive modern interface

# ⚡ Installation

Clone the repository:

```bash
git clone https://github.com/jainleo2006jv-gif/qr-generator-streamlit.git
```

Move into project folder:

```bash
cd qr-generator-streamlit
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run Streamlit app:

```bash
streamlit run app.py
```
